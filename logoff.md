## Session Handoff request

When the human asks you to read the loggoff file that means they are done with their session and want to save the knowledge you discussed this session.

1. Archive the current session with it's 'create date and time' appended to the end of it's name to this folder `documentation/sessions`
2. Update the agents file with anything that has changed from this current session
3. Create a new session handoff document `/sessionhandoff.md`

- This handoff should include

* Be concise but complete
* Capture descsions not discussions
* Do not include dead end approacheds unless they are important context
* if changes architectureal changes were made document them
* Files worked on
* Bugs fixed
* enhancements done
* Suggested next steps if you have any
* Open questions
* Clarrifcations made
* Assume that this handoff will be read at a later date with no conversation history
* As the last step, provide a prompt for the next session to start to the bot can pick up with the best context possible.
