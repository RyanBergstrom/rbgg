# Session: MCTS Heuristic Scoring Improvements
**Date**: 2026-09-16

## Summary
Improved the `score_moves` heuristic in Lost Cities to better penalize bad plays and reward good plays during MCTS rollouts.

## Changes Made

### 1. New Play Scoring Function (`compute_play_score_v2`)
- **File**: `app/games/lost_cities/validator.py`
- Sequential constraint: counts only cards ≥ scored card, pre-computes `highest_numbered_guaranteed`
- Investment multiplier: counts only cards played after investments
- Killed card penalty: sum of lower-numbered cards × 3
- Wasted investment penalty: investments in hand × 15 when playing numbered card
- 8-card bonus: +20 if expedition reaches 8 cards

### 2. Updated Discard Scoring
- **File**: `app/games/lost_cities/validator.py`
- Cards that can't be played → score 10 (good discard, frees hand)
- Cards that can play with positive value → score 0.5 (don't discard)
- Cards that can play with negative/zero value → score 0 (dead cards)

### 3. Updated `_weighted_choice` Function
- **File**: `app/core/mcts.py`
- Changed from shifting (min → 0) to clamping (max(0, score))
- Prevents bad moves from getting inflated probability due to worst move anchoring

## Test Results
- 71/72 tests pass (1 pre-existing failure: `test_expedition_investment_always_legal`)
- New test files created:
  - `tests/test_score_moves_debug.py` (14 tests)

## Key Decisions
- Kill penalty multiplier: 3× (makes white-4 negative when killing white-3)
- Discard scoring: simple threshold (10/0.5/0) based on play value
- Weight clamping: negatives become 0, no shifting
